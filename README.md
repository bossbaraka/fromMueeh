# مُريح | Mureeh — Talent & Service Provider Acquisition System

نظام تقديم احترافي لشبكة مُريح: يستقطب المستقلين والمبدعين والمطورين ومقدّمي الخدمات،
ويفهم مهاراتهم وطريقة تفكيرهم وأعمالهم، ثم يبني قاعدة بيانات ترجع إليها مُريح عند وجود مشروع مناسب.

> **ليس طلب توظيف.** هذا طلب انضمام إلى **Mureeh Talent Network**.
> لا عقد عمل، ولا راتب ثابت، ولا ضمان مشاريع. المقابل يكون مقابل الخدمة أو المشروع المنفّذ،
> ويُتفق على النطاق والمخرجات والمدة والسعر بشكل منفصل قبل بدء أي تنفيذ.

---

## ما يميّز هذا النظام

| المرحلة | ما يفعله النظام |
| --- | --- |
| **Understand** | هوية، مجالات، مستوى، بيئات عمل، روابط |
| **Think** | 12 سؤالًا فكريًا بصياغة طويلة — يجيب المتقدّم على **4 يختارها** منها على الأقل (المشكلة قبل الحل، الجودة/السرعة، قيمة العمل مع AI، حدود المسؤولية…) |
| **Verify** | 3 مشاريع: المشكلة · ما نفّذته بنفسك · الأدوات · النتيجة — للتمييز بين «شاركت» و«نفّذت» |
| **Match** | أنواع المشاريع، طريقة التعاون، التوفر، السعة الأسبوعية |
| **Collaborate** | نموذج التعاون بوضوح + إقرارات الشفافية قبل الإرسال |

كل إرسال ينتهي بصف واحد في Google Sheet (**Talent Applications**) بحالة `NEW`، والقرار النهائي بشري دائمًا.

## التشغيل السريع

```bash
npm install
cp .env.example .env.local     # ثم املأ قيم Google Sheets (أو اتركها فارغة لوضع العرض المحلي)
npm run dev                    # http://localhost:3000
```

الصفحات:

| المسار | الوصف |
| --- | --- |
| `/` | الصفحة الرئيسية: الفلسفة، المراحل الخمس، الرحلة، الأسئلة الشائعة |
| `/apply` | النموذج: 6 فصول في شاشة مقسّمة (ريل كحلي بالعلامة والتقدم + لوحة عاجية) + شاشة نجاح بختم ذهبي |
| `/team` | لوحة داخلية لعرض قاعدة بيانات المهارات (محمية في الإنتاج) |
| `/api/health` | حالة التكامل (لا يكشف أي مفاتيح) |

### أوامر مفيدة

```bash
npm run typecheck      # فحص الأنواع
npm run build          # بناء إنتاجي
npm run sheets:connect # ربط Google Sheets بأمر واحد (تحقق + إنشاء التاب + صف العناوين)
npm run selftest       # فحوصات انحراف المخطط (Form ↔ Sheet) — 8 فحوصات
npm run sheet:headers  # طباعة/كتابة صف عناوين الأعمدة (CSV أو --tsv)
npm run report -- <submission_id> --out docs/report.md   # تقرير دعم القرار لطلب واحد
```

> `npm run sheets:connect --check` يتحقق من المفاتيح والاتصال **بدون أي كتابة**.
> وإن نقص شيء، يطبع لك الخطوات الناقصة بالعربية خطوة بخطوة.

## حلقة المراجعة البشرية (لوحة `/team`)

قاعدة البيانات ليست أرشيفًا: كل طلب يمكن للفريق أن يراجعه ويحرّكه داخل نفس الورقة.

| ما يفعله الفريق | أين يُكتب |
| --- | --- |
| تغيير الحالة (`NEW → REVIEWING → SHORTLISTED → CONTACTED → ACTIVE / NOT_A_CURRENT_FIT`) | عمود `application_status` + `last_updated` |
| ملاحظات المراجع | عمود `reviewer_notes` (للفريق فقط) |
| توليد دعم القرار | عمود `ai_decision_support` |

كل ذلك عبر `POST /api/team/review` بترويسة `x-admin-token` (= `ADMIN_ACCESS_TOKEN`).
في الإنتاج دون ضبط المفتاح يُرفض الطلب (503) بدل أن يبقى المسار مفتوحًا.

### محرّك دعم القرار — `src/lib/decision-support.ts`

**دعم قرار فقط. لا قبول، ولا رفض، ولا ترتيب.** الطبقتان:

1. **حتمية دائمًا (`mureeh-signals/v1`)** — بلا أي API خارجي، وقابلة للتفسير:
   * **ثيمات التفكير** (11 ثيمة: المشكلة أولًا، القياس، المستخدم، التفكير النُظُمي، الجودة، ملكية العمل، التعلّم، توظيف AI، التواصل، إدارة المخاطر، ضبط النطاق) — كل ثيمة بثقة **ومقتطف من إجابته** كدليل.
   * **إشارات**: `قوة` / `يحتاج سؤالًا` / `تحقّق` — مثل «نتائج بلا مؤشر قياس»، «مفردات تقييم ذاتي بلا دليل»، «تعارض محتمل بين البدء والسعة».
   * **اكتمال الوصف** (ليس تقييمًا للشخص) + الإجابات الرقيقة.
   * **ملاءمة مبدئية** لأنواع المشاريع + **أسئلة مقترحة للتواصل الأول**.
2. **اختيارية (`+llm`)** — عند ضبط `DECISION_SUPPORT_API_KEY` و `DECISION_SUPPORT_MODEL` تُضاف خلاصة نصية من 4 أسطر للقراءة السريعة (مهلة 12 ثانية، وفشلها يُتجاهل).

نموذج حقيقي لمخرجات المحرّك: **[docs/decision-support-sample.md](docs/decision-support-sample.md)**

> **تفصيل عربي مهم:** الأرقام العربية-الهندية (`٤٠٠`، `١٢%`، `٣٥٠٠ – ٩٠٠٠`) تُحوَّل إلى ASCII قبل التحقق والتحليل والتسعير (`toAsciiDigits`)، وأرقام الهاتف تُخزَّن موحّدة — حتى تبقى قاعدة البيانات قابلة للاستعلام.

## إعداد Google Sheets

راجع **[docs/GOOGLE_SHEETS_SETUP.md](docs/GOOGLE_SHEETS_SETUP.md)** (بالإنجليزية، خطوة بخطوة:
حساب خدمة، مشاركة الملف، متغيّرات البيئة، تهيئة الأعمدة، استكشاف الأخطاء).

باختصار:

```bash
# 1) متغيّرات البيئة في .env.local
GOOGLE_SERVICE_ACCOUNT_EMAIL="mureeh-sheets@your-project.iam.gserviceaccount.com"
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
GOOGLE_SHEET_ID="1AbCdEf..."
GOOGLE_SHEET_TAB="Talent Applications"

# 2) تهيئة الورقة (إنشاء التاب + صف العناوين) — تحتاج ADMIN_BOOTSTRAP_TOKEN
curl -X POST http://localhost:3000/api/talent/setup -H "x-admin-token: $ADMIN_BOOTSTRAP_TOKEN"

# 3) التحقق
curl http://localhost:3000/api/health
```

> ⚠️ بيانات الاعتماد تُقرأ من متغيّرات البيئة على السيرفر فقط (`src/lib/sheets.ts`).
> لا يوجد أي مفتاح في الواجهة أو في الـ bundle.

## الحماية من الإساءة

* **Honeypot** مخفي + فحص زمن التعبئة (أقل من ثانيتين = بوت) → ردّ نجاح وهمي بلا تخزين.
* **Rate limit**: 5 طلبات لكل IP خلال 15 دقيقة (`RATE_LIMIT_MAX` / `RATE_LIMIT_WINDOW_MINUTES`).
* **منع تكرار البريد**: تحقق من عمود `email` → `409 DUPLICATE`.
* **Cloudflare Turnstile** (اختياري): يُحمَّل فقط عند ضبط `NEXT_PUBLIC_TURNSTILE_SITE_KEY`، ويُتحقق منه على السيرفر.
* **تحقق مزدوج**: Zod على الواجهة والسيرفر بنفس القواعد، والسيرفر لا يثق بالواجهة أبدًا.

## إمكانية الوصول

حقول بعناصر HTML أصلية (label/input حقيقية)، تنقل كامل بالكيبورد، حالات تركيز واضحة،
`aria-live` للأخطاء وتغيير الخطوات، نقل التركيز إلى عنوان الصفحة الجديدة،
احترام `prefers-reduced-motion`، وتباين ألوان واعٍ بـ WCAG.

## الهوية البصرية

Warm Ivory `#F7F4ED` · Champagne Gold `#D4AF37` / `#C9A227` · Deep Navy `#0B1320` ·
Charcoal `#15171A` — حدود رقيقة رفيعة، ظلال هادئة، وحركة لا تُستخدم إلا للتوجيه والتغذية الراجعة والاستمرارية.

صفحة التقديم مبنية كشاشة مقسّمة («Atelier»): ريل كحلي ثابت يحمل العلامة وفصول الطلب
والتقدّم وأدلة على طريقة عمل المنصة، وعمود عاجي للنموذج بترويسة فصل مرقّمة بخط ذهبي مفرّغ،
وبطاقات اختيار على شكل حبوب (segmented pills) وبطاقات أسئلة تفكير قابلة للفتح، وشريط سفلي
لاصق بزر ذهبي تعبره لمعة عند التحويم. شاشة النجاح ختم ذهبي بحلقات متحركة على الكحلي.

الخط: **IBM Plex Sans Arabic** (مُضمّن في الـ bundle عبر حزمة `@fontsource` — استضافة محلية
كاملة، بلا طلبات خارجية عند المستخدم وبلا اعتماد على الشبكة وقت البناء).
